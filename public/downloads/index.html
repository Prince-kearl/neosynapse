Neo Synapse

Install Neo Synapse on your phone

Android users can download the APK directly. iPhone and iPad users can add Neo Synapse to the Home Screen from Safari.

Android app download

Install the latest Android build of the Neo Synapse mobile app.

Download Android APK If the download is unavailable, generate it with npm run mobile:apk:export before deploying the site.

iPhone or iPad

Use Safari to add Neo Synapse to your Home Screen. This does not require an Apple Developer account.

  1. Open this page in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Tap Add.
