# Neo Synapse Production Domain Setup

Production domain: `neosynapseai.com`

This project is configured to use `https://neosynapseai.com` as the canonical app origin for authentication callbacks, password reset links, invitation links, PWA metadata, and public download pages.

## 1. DNS Records

Add these records at the domain registrar or DNS provider for `neosynapseai.com`.

For Vercel hosting:

| Type | Name | Value |
| --- | --- | --- |
| A | `@` | `76.76.21.21` |
| CNAME | `www` | `cname.vercel-dns.com` |

After DNS propagates, add both domains in Vercel:

- `neosynapseai.com`
- `www.neosynapseai.com`

Set `neosynapseai.com` as the primary domain and redirect `www.neosynapseai.com` to it.

## 2. Frontend Environment

Set these variables in the production hosting dashboard:

```sh
VITE_SUPABASE_PROJECT_ID=yzdnjmgpfuifgdizzlpz
VITE_SUPABASE_URL=https://yzdnjmgpfuifgdizzlpz.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=<your Supabase anon/publishable key>
VITE_APP_URL=https://neosynapseai.com
```

Then redeploy the web app.

## 3. Supabase Auth URLs

In Supabase Dashboard, open:

`Authentication` -> `URL Configuration`

Set:

```text
Site URL: https://neosynapseai.com
```

Add these redirect URLs:

```text
https://neosynapseai.com/**
https://neosynapseai.com/auth/reset-password
https://neosynapseai.com/auth/invite-accept
http://localhost:5173/**
http://localhost:8080/**
```

The localhost entries are only for development.

## 4. Supabase Edge Function App URL Secret

Set the public app URL as a Supabase secret so any server-generated links use the production domain:

```sh
supabase secrets set APP_URL=https://neosynapseai.com --project-ref yzdnjmgpfuifgdizzlpz
```

This is especially important for invitation links generated by Edge Functions.

## 5. Build And Verify

```sh
npm run test
npm run mobile:build
```

Manual production checks:

- Visit `https://neosynapseai.com`.
- Visit `https://neosynapseai.com/downloads`.
- Create an invitation and confirm the generated link starts with `https://neosynapseai.com/auth/invite-accept`.
- Request a password reset and confirm the email returns to `https://neosynapseai.com/auth/reset-password`.
- Sign in as patient, professional, and admin.
